# 宇宙シミュレーター 第1段階 設計書

作成日: 2026-11-02 / 状態: レビュー待ち

| 1 | 宇宙スケール(ビッグバン→現在→遠い未来)+時間操作 | ✅ |

最終目標は「いまの世界の再現」と、生命・文明まで見られる宇宙。
ただし以下を明確に区別する(UIにも明示する)。
- **物理計算**: 宇宙膨張、重力による構造形成(第1段階)
- **実データ**: 太陽系・地球(第2段階)
- **確率・仮説モデル**: 他の星の生命・文明(第3・4段階)。予測ではなくフィクションの実験場。

## 1. 第1段階のゴール

ブラウザで動く3D宇宙シミュレーター。
- ビッグバンから約138億年後(現在)、さらにその先の遠い未来までを再生できる
- デフォルト速度は **1分 = 1億年**
- 対数スライダーで自由に倍速、一時停止、逆再生
- 年表のイベントへジャンプできる
- 3Dで自由にカメラを動かせる

## 2. 技術方針

- 実行形態: ブラウザ(Chrome/Edge 最新版)。`index.html` を開くだけで動く
- 描画/計算: Three.js + **WebGPU**(コンピュートシェーダーでN体計算)
- 外部ライブラリは CDN から固定バージョンで読み込む
- 粒子数: 目標 50万〜100万(GPU性能に応じて自動調整、設定で変更可)
- WebGPU 非対応ブラウザでは、その旨を表示し粒子数を絞った簡易表示にフォールバックしない(第1段階では非対応と明示)

## 3. 構成(3レイヤー)

### 3.1 宇宙論エンジン(CPU, 純関数)
- ΛCDM 宇宙: H0 ≈ 67.7 km/s/Mpc、Ωm ≈ 0.31、ΩΛ ≈ 0.69(+放射)
- 入力: 宇宙時間 t → 出力: スケール因子 a(t)、赤方偏移 z、温度 T、ハッブル率 H
- 初期は放射優勢、のち物質優勢、現在以降は暗黒エネルギー優勢(加速膨張)
- 単体でテストできる(既知の値: t=138億年で a≈1 など)

### 3.2 N体エンジン(GPU)
- 共動座標で粒子を扱い、膨張は a(t) で与える
- 力の計算: Particle-Mesh 法(格子に質量を割り当て→FFTでポテンシャル→力)
- 時間積分: leapfrog(時間反転可能)
- 初期条件: CMB 由来のランダムなゆらぎ(パワースペクトルから生成、シード固定可)
- 開始時刻: 再結合(約38万年)直後。それ以前は 3.3 の演出で描く

### 3.3 描画・演出
- **〜38万年(プラズマ時代)**: 粒子ではなくシェーダー演出。温度に応じた色と明るさ、密度ゆらぎのマップ
- **38万年〜**: N体粒子を点として描画(密度で明るさ・色を変える)。大規模構造(フィラメント・銀河団)が育つ
- **遠い未来**: 加速膨張で銀河団が互いに遠ざかり、星の光が減る表現(星形成率の曲線に沿った明るさ)
- 恒星・銀河の個別描写は粒子では不可(第2段階の領分)。第1段階では「密度に応じた輝点」として表現する

### 3.4 UI
- 時間コントロール: 再生/停止、逆再生、対数スライダー倍速(例: 0.01倍〜10万倍相当)、現在値表示(経過時間・赤方偏移・温度・宇宙の大きさ)
- 年表バー: 主なイベントへジャンプ(インフレーション、元素合成、再結合、暗黒時代、最初の星、銀河形成、太陽系誕生、現在、遠い未来)
- カメラ: 回転、パン、ズーム(第1段階では宇宙スケールのみ)
- 各時代のON/OFF解説テキスト(教育用)

## 4. 時間の扱い

- 基本: 実時間1分あたり宇宙時間1億年(1倍速)
- 138億年に達するまで約138分かかるため、倍速スライダーで加速するのが通常運用
- ビッグバン直後〜数分は桁が極端に違うため、**対数時間モード**(自動切替)で扱う
- 逆再生: leapfrog は可逆だが誤差が蓄積するので、一定間隔でスナップショットを保存し、保存点から再計算して巻き戻す

## 5. エラー処理

- WebGPU 非対応: 理由と対応ブラウザを案内する画面
- GPU性能不足: 粒子数を自動で段階的に下げる(下げた旨を表示)
- 計算の発散(NaN): 検出してそのスナップショットへ戻し、警告を表示

## 6. テスト方針

- 宇宙論エンジン: 既知の値(現在の宇宙年齢、z=1100 の時期、a の単調性)を自動テスト
- N体: 粒子数少での保存則(運動量)確認、時間反転して初期配置に戻るか(許容誤差内)
- 描画/UI: ブラウザで実際に動かして確認(スクリーンショット、コンソールエラー無し)

## 7. 第1段階の対象外

- 銀河・恒星・惑星の個別表示(第2段階)
- 太陽系・地球の実データ(第2段階)
- 生命・文明(第3・4段階)
- 保存/共有機能、モバイル最適化
