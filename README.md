# 宇宙シミュレーター

ビッグバンから現在、遠い未来までを3Dで再現するブラウザ用シミュレーター(WebGPU N体計算)。
最新の Chrome / Edge で index.html を開くと動きます。


## 追加機能(第3b〜4の入口)
- 👁 ボタン / Hキー: 画面の表示・非表示を切り替え
- 地表: 生き物(植物・動物・鳥・魚・知的生命)と建物を手続き生成で描画。生命の段階は確率モデル(仮説)
- 🏛 文明の実験: 個人が技術を組み合わせて試す創発モデル(civ.js)。順番・時期は世界ごとの乱数で、筋書きなし
- 調整用: `node tests/civ.run.js 3 400000`
- 🌱 生命を探す: 銀河の中の恒星を自動で調べ、生命のいる惑星を一覧(押すと飛ぶ)。銀河の画面には、押しやすい ☆ 印(太陽に近い恒星)が出る
- 植物の色は惑星ごとに緑・黄・赤・紫・青緑・黒(軌道から見た色と地表の色は同じ)
- 文明: プログラムに到達すると、その世界で書かれたプログラムを実際に実行して表示。道と町が文明の段階に応じて広がる
