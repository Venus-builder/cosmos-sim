# 宇宙シミュレーター

ビッグバンから現在、遠い未来までを3Dで再現するブラウザ用シミュレーター(WebGPU N体計算)。
最新の Chrome / Edge で index.html を開くと動きます。


## 追加機能(第3b〜4の入口)
- 👁 ボタン / Hキー: 画面の表示・非表示を切り替え
- 地表: 生き物(植物・動物・鳥・魚・知的生命)と建物を手続き生成で描画。生命の段階は確率モデル(仮説)
- 🏛 文明の実験: 個人が技術を組み合わせて試す創発モデル(civ.js)。順番・時期は世界ごとの乱数で、筋書きなし
- 調整用: `node tests/civ.run.js 3 400000`
- 🌱 生命を探す: 銀河の中の恒星を自動で調べ、生命のいる惑星を一覧(押すと飛ぶ)。銀河の画面には、押しやすい ☆ 印(太陽に近い恒星)が出る
- 植物の色は惑星ごとに緑・黄・赤・紫・青緑・黒(軌道から見た色と地表の色は同じ)
- 文明: プログラムに到達すると、その世界で書かれたプログラムを実際に実行して表示。道と町が文明の段階に応じて広がる
- 🧬 生態系(eco.js): 0.6km四方の動物を一匹ずつ動かす(餌・捕食・群れ・繁殖・遺伝・種分化・絶滅・大量絶滅)。近くの個体は本物の状態を表示
- 🌍 いまの地球シナリオ(scenario.js): 統計の概数を初期値に、条件を変えて比べる年次モデル(予測ではない)
- テスト: `node tests/eco.test.js` / `node tests/scenario.test.js`
- 🌌 いろいろな天体: ブラックホール(重力レンズで描画)・超大質量BH・パルサー・マグネター・白色矮星・超新星残骸・星雲・惑星状星雲・球状星団。銀河の画面に紫の印が出る
- 🚀 自由飛行: 宇宙・銀河・恒星系で、W/A/S/D・Q/E や 前進/後退ボタンで好きなところへ。ホイール/ピンチで速さ
- 地表は描画の細かさを自動調整(重いと下がる)
- 初期宇宙: 温度・中性子/陽子比・ヘリウム4の割合(約25%)・水素の電離度(Saha式)を画面に表示
- 文明: 集団の分裂・交易・戦争・併合。生態系と土地の実りでつながる(人が増えると実りが減り、実りが減ると養える人数が減る)
- 生態系: 水中の生物も一匹ずつ。時間が溜まったときは粗い刻みで早送り
